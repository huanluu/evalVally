Did the agent actually do the job?

This prototype turns three plain-language tasks into repeatable tests. Vally runs a real Copilot agent in an isolated workspace, records its behavior, checks the result with deterministic graders, and publishes evidence in CI.

How one eval flows

The YAML spec is the contract. It states the task, how the agent should be run, and the objective evidence required for a pass.

Stimulus

A prompt or multi-turn conversation defines the behavior under test.

Executor

Vally starts a real Copilot SDK session in an isolated workspace.

Trajectory

Turns, tool calls, tokens, timing, output, and errors are recorded.

Graders

File, regex, executable, completion, and output checks inspect the result.

Score

The suite passes only when every configured check succeeds.

What it proves

The important claim is not that an agent succeeded once. It is that the same evaluation contract runs locally and in CI and leaves inspectable evidence.

Proven by this prototype

  • Vally can execute a real Copilot agent from a versioned eval spec.
  • Deterministic graders can validate files, executable behavior, and conversation output.
  • The same suite runs unattended in GitHub Actions with secret-based authentication.
  • Each run emits durable results: JSONL, Markdown, JUnit, trajectories, artifacts, and traces.
  • A failed grader makes the workflow fail, so eval quality can gate a pull request.

Not proven yet

  • Production reliability across a large or representative benchmark.
  • Statistical consistency; each case currently runs only once.
  • Quality of subjective work that requires an LLM judge or human review.
  • Security, privacy, cost, latency, or cross-model performance at scale.
  • Integration with the full OMR Harness workflow, skills, work items, and Office builds.

How automation works

The repository separates cheap validation from credentialed execution. That keeps configuration errors fast while preserving real-agent evidence for every run.

1 · Trigger

Push or pull request

GitHub Actions checks out the versioned eval suite.
